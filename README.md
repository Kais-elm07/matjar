# متجري: متجر إلكتروني عربي

متجر إلكتروني بواجهة عربية (من اليمين لليسار)، مصمم للجوال أولاً، ومبني بـ Next.js وPostgreSQL.
الخطة الكاملة ومراحل التنفيذ في الملف [خطة-المتجر-الإلكتروني.md](خطة-المتجر-الإلكتروني.md).

**الحالة الحالية:** المرحلة 1 (الهيكل الأساسي) مكتملة. التالي: المرحلة 2 (الكتالوج).

## المتطلبات

- Node.js 22 أو أحدث
- pnpm 12: `npm install -g pnpm`
- PostgreSQL 16 أو أحدث مثبت على الجهاز (لقاعدة بيانات التطوير)

## التشغيل لأول مرة

```bash
pnpm install
cp .env.example .env
pnpm db:start
pnpm db:migrate
pnpm dev
```

ثم افتح http://localhost:3000

## التشغيل اليومي

```bash
pnpm db:start
pnpm dev
```

الأمر `pnpm db:start` يكفي مرة واحدة بعد كل إعادة تشغيل للجهاز.

## الأوامر

| الأمر              | الوظيفة                                                   |
| ------------------ | --------------------------------------------------------- |
| `pnpm dev`         | تشغيل الموقع للتطوير على المنفذ 3000                      |
| `pnpm build`       | بناء نسخة الإنتاج                                         |
| `pnpm start`       | تشغيل نسخة الإنتاج بعد البناء                             |
| `pnpm check`       | فحص التنسيق والأخطاء والأنواع دفعة واحدة                  |
| `pnpm format`      | تنسيق كل الملفات تلقائياً                                 |
| `pnpm db:start`    | تشغيل قاعدة البيانات المحلية (وتهيئتها في أول مرة)        |
| `pnpm db:stop`     | إيقاف قاعدة البيانات المحلية                              |
| `pnpm db:status`   | عرض حالة قاعدة البيانات المحلية                           |
| `pnpm db:migrate`  | إنشاء ترحيل جديد بعد تعديل `prisma/schema.prisma` وتطبيقه |
| `pnpm db:generate` | إعادة توليد كود Prisma بعد أي ترحيل                       |
| `pnpm db:studio`   | فتح واجهة لتصفح البيانات وتعديلها                         |

## أين أغيّر...

| ما تريد تغييره             | الملف                                       |
| -------------------------- | ------------------------------------------- |
| اسم المتجر والوصف والروابط | `src/config/site.ts`                        |
| ألوان الهوية والزوايا      | `src/app/globals.css` (قسم `:root`)         |
| الخط العربي                | `src/app/layout.tsx` و `src/fonts`          |

## هيكل المشروع

```
prisma/                 مخطط قاعدة البيانات والترحيلات
scripts/db-local.mjs    إدارة قاعدة البيانات المحلية
src/app/(store)/        صفحات واجهة المتجر (الرئيسية الآن)
src/app/api/health/     فحص حالة الموقع وقاعدة البيانات
src/app/not-found.tsx   صفحة 404 العربية
src/components/layout/  الرأس والتذييل وقائمة الجوال والبحث
src/components/store/   مكونات المتجر المشتركة
src/components/ui/      مكونات shadcn/ui الأساسية
src/config/site.ts      إعدادات المتجر العامة
src/lib/db.ts           الاتصال بقاعدة البيانات
src/fonts/              ملفات خط Cairo (ترخيص OFL)
```

## قاعدة البيانات المحلية

الأمر `pnpm db:start` يشغّل نسخة PostgreSQL مستقلة خاصة بالمتجر باستخدام PostgreSQL المثبت على جهازك:

- تعمل على المنفذ 5433 وعلى جهازك فقط، بدون كلمة مرور.
- لا تمس خدمة PostgreSQL الأصلية على المنفذ 5432.
- بياناتها في المجلد `%LOCALAPPDATA%\matjar\pgdata`.

إن أردت استخدام خدمة PostgreSQL الأصلية بدلاً منها، أنشئ فيها قاعدة باسم `matjar` وعدّل `DATABASE_URL` في ملف `.env`.

## ملاحظات تقنية مهمة

- **Next.js 16.4 مع Cache Components:** جلب البيانات ديناميكي افتراضياً. أي جزء يقرأ بيانات متغيرة يوضع داخل `<Suspense>` أو يُخزَّن بـ `"use cache"`. التوثيق المطابق للإصدار موجود في `node_modules/next/dist/docs`.
- **Prisma 7.10:** ملف الإعداد اسمه `prisma7.config.ts`، والأمر `pnpm db:migrate` لا يولّد الكود تلقائياً، فشغّل بعده `pnpm db:generate`.
- **إصدارات Prisma مثبتة على 7.10.1:** الوسم `latest` لأداة prisma على npm يشير حالياً إلى نسخة تجريبية من الإصدار 8، فلا تحدّثها دون مراجعة.
- **الخط مستضاف داخل المشروع:** بناء الموقع لا يحتاج اتصالاً بـ Google Fonts.
